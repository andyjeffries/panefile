# Dynamic dependencies of the pf binary on Linux (Arch, GCC, Release).
# Regenerate: scripts/check-dependencies.sh build/release/bin/pf > docs/dependencies-linux.txt
#
# §3.4: every optional feature must arrive as a plugin opened on first use, not
# as a DT_NEEDED entry. Nothing for syntax highlighting, media, PDF or video
# thumbnails appears below, which is the property this file exists to protect.
#
# libQt6DBus and libdbus-1 are pulled in transitively by Qt itself rather than
# by anything Panefile links; M8's udisks2 monitor (§7.11) uses them but opens
# no bus connection until the sidebar's Devices section is first shown.
#
# libQt6Network is deliberately absent. §10.3 names QLocalServer, and linking
# QtNetwork for it added twenty-eight entries to this list — OpenSSL, Kerberos,
# libcurl, nghttp2, and libproxy, which embeds a JavaScript interpreter — every
# one mapped and relocated at every launch, for a Unix domain socket that never
# speaks TCP, TLS or HTTP. app/SingleInstance.cpp uses POSIX sockets and
# QSocketNotifier, which is QtCore.
