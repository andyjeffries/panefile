# Time to first paint, in ms, for:
#   QT_QPA_PLATFORM=offscreen pf --startup-trace --quit-after-paint <fixture>
# Median of 20 runs after 3 warmups, Release build, against the 2,200-entry
# fixture that scripts/make-fixture.sh generates.
#
# macOS 26.3, Apple silicon, Qt 6.10.2. Recorded at M3.
#
# THE PLATFORM PLUGIN IS PART OF THE MEASUREMENT. This baseline is taken under
# `offscreen`, which is markedly slower than `cocoa` here — it does software
# rendering with no font or graphics acceleration. Under cocoa the same build
# reaches first paint in about 255 ms. Neither number is wrong; they are
# measurements of different things, and comparing across them produces a
# "regression" that is nothing of the sort. That happened once already, when the
# script was switched to offscreen so that benchmarking twenty-three launches
# would stop opening twenty-three windows over whatever the developer was doing.
#
# A relative baseline: macOS is not held to the 80 ms absolute target of §11,
# for the reasons in docs/startup-budget.md.
648.2
